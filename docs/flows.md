# Flujos principales

## Registro de especialista

1. Usuario completa formulario
2. Backend valida datos
3. Se crea User
4. Se crea Specialist
5. Se devuelve sesión/token

## Reserva de turno

1. Paciente elige especialista
2. Elige fecha
3. Elige horario disponible
4. Backend valida disponibilidad
5. Se crea Appointment
